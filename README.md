# 🎮 Rock Paper Scissors Game Using Python

## 📌 Project Description
Rock Paper Scissors is a simple interactive game developed using Python and Tkinter. The player competes against the computer by choosing Rock, Paper, or Scissors. The application determines the winner of each round and keeps track of the scores.

## ✨ Features
- 🪨 Choose Rock, Paper, or Scissors.
- 🤖 Play against the computer's randomly selected move.
- 🏆 Automatically determine the winner of each round.
- 📊 Track player and computer scores.
- 🤝 Detect draw situations.
- 🔄 Reset scores and start a new game.
- 🖥️ User-friendly graphical interface.

## 🛠️ Technologies Used
- **Python** – Game logic and programming.
- **Tkinter** – Graphical user interface.
- **Random Module** – Generates the computer's moves.

The game window will open. Select Rock, Paper, or Scissors to play against the computer.

## 🎯 Game Rules
- **Rock beats Scissors**
- **Scissors beats Paper**
- **Paper beats Rock**
- If both choose the same option, the round is a draw.

## 🕹️ How to Play
1. Launch the application.
2. Click one of the three choice buttons.
3. View your choice and the computer's choice.
4. Check the result and updated scores.
5. Continue playing as many rounds as you want.
6. Click **Reset Score** to reset both scores.
